# Social Archiver Homebrew tap

Official Homebrew tap for the Social Archiver CLI.

## Install

```sh
brew install hyungyunlim/tap/social-archiver-cli
```

Then confirm the installation:

```sh
social-archiver --version
```

The formula supports Apple Silicon and Intel macOS, plus x86_64 Linux.

## Upgrade

```sh
brew update
brew upgrade social-archiver-cli
```

Release archives and checksums are published in the
[public release repository](https://github.com/hyungyunlim/obsidian-social-archiver-releases/releases).
